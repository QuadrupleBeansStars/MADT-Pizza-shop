Step 3 of 5 · Process

Clean the data

Clean the data once, in one place, so everything after it can trust it.

Comes in

Messy rows from the raw layer.

→

What we do

  • Time: any style to Bangkok time
  • Day: the shop day is 10:00 to 02:00
  • Twins: same order twice, keep one
  • Names: many names, one item
  • Options: only from the pick list
→

Goes out

One clean row per real order.

Odd notes go to an "Invalid" row, so we can see them.

Example

MLOps · 2 of 2

How far ahead? How much extra?

We do not order every day, so the forecast must reach the end of each order cycle.

StockOrder onLasts untilLook ahead
Dough, cheese, toppingsMondayThursday3 days
Dough, cheese, toppingsThursdayMonday4 days
Drinks and boxesMondaynext Tuesday8 days

Assumed supplier terms. The owner confirms.

Order too much

Throw away food. Costs about 30% of the price.

Order too little

Lose the sale. Costs about 70%.

So we order extra

We cover 70% of past cycles. Hawaiian L: forecast 89, order 130.

Error per day 0.30. Per cycle 0.16.

RULE Forecast to the end of the cycle. Order extra where running out costs more than waste.
