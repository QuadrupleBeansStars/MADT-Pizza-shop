1 · ขอบเขต

อยู่ในขอบเขต

  • แหล่งข้อมูลการขายสองแหล่ง: POS (QR, โทรศัพท์) และไฟล์ export ของแอปเดลิเวอรี
  • conformed dimension หกตัวและ bridge หนึ่งตัว
  • fact สามตัว: FCT_ORDER, FCT_ORDER_LINE, FCT_ORDER_LINE_MODIFIER
  • aggregate table สามตัว หนึ่งตัวต่อหนึ่ง fact
  • ผู้ใช้กลุ่มเดียว: แดชบอร์ดของเจ้าของร้าน

ยังไม่อยู่ในขอบเขต

  • สต็อก การสั่งของ และการสั่งซื้อ
  • กะงานและค่าแรง
  • การชำระเงินและโปรโมชัน
  • เวลาการจัดส่ง
  • โมเดลพยากรณ์และการแบ่งกลุ่มลูกค้า

ขอบเขตเล็กลงแต่กฎการออกแบบไม่เปลี่ยน ยังเป็น Kimball dimensional warehouse ตาม MADT8102 บทที่ 5: surrogate key แบบ _key, special-case row (0 ไม่เกี่ยวข้อง, 1 ไม่ทราบ, 2 ไม่ถูกต้อง) แทน key ที่เป็น NULL, junk dimension สำหรับสถานะออร์เดอร์, เลขออร์เดอร์และเลขบรรทัดเป็น degenerate dimension และเทียบ fact ด้วยการ drill across

4 · Dimension และ fact table

DimensionHierarchy และหมายเหตุ
DIM_DATEวัน › เดือน › ไตรมาส › ปี ตามวันทำการ (10:00–02:00)
DIM_CHANNELช่องทาง › ประเภทช่องทาง (Dine-in / Delivery) ช่องทางของร้านหรือแพลตฟอร์ม อัตราคอมมิชชัน
DIM_CUSTOMERสมาชิกบนช่องทางของร้าน แถว 0 สำหรับออร์เดอร์ที่ไม่มีลูกค้าระบุตัว
DIM_MENU_ITEMSKU › เมนู › หมวด เก็บราคาแบบ SCD2 (Pepperoni L คือแถว 102 และ 106)
DIM_MODIFIERชีสเพิ่ม ไม่ใส่พริก… แบบ add / remove / substitute
DIM_ORDER_INFOjunk dimension: สถานะออร์เดอร์ flag การยกเลิก
BRG_CHANNEL_MENU_ITEMชื่อและราคาบนแพลตฟอร์ม → SKU ของเรา
Fact tableGrain: หนึ่งแถว =Measureทำไมต้องแยกตาราง
FCT_ORDERออร์เดอร์หนึ่งใบ ทุกช่องทางยอดขาย ส่วนลด ค่าส่ง คอมมิชชัน รายได้สุทธิเงินระดับออร์เดอร์ต้องไม่ซ้ำในทุกบรรทัด
FCT_ORDER_LINEเมนูหนึ่งรายการในออร์เดอร์หนึ่งใบจำนวน ราคาต่อหน่วย (snapshot) ส่วนลด ยอดสุทธิของบรรทัดรู้ว่าอะไรขายได้ ที่ราคาที่จ่ายจริง
FCT_ORDER_LINE_MODIFIERmodifier หนึ่งตัวบนบรรทัดหนึ่งบรรทัดจำนวน ราคาส่วนเพิ่ม (snapshot)ของเพิ่มเป็นแถว ไม่ใช่คอลัมน์ text จึงนับได้

5 · Aggregate table

Aggregate tableGrain: หนึ่งแถว =สร้างจากคอลัมน์
mart_channel_dailyวันทำการ × ช่องทางFCT_ORDERorders, gross_sales_thb, commission_thb, net_revenue_thb, ชื่อวัน flag วันหยุดสุดสัปดาห์ ประเภทและเจ้าของช่องทาง
mart_sales_dailyวันทำการ × ช่องทาง × SKUFCT_ORDER_LINEunits_sold, orders, item_sales_thb, ชื่อเมนู หมวด ไซซ์
mart_modifier_dailyวันทำการ × ช่องทาง × modifierFCT_ORDER_LINE_MODIFIERtimes_applied, modifier_revenue_thb, ประเภท modifier หมวดของเมนู

ทุกตัวสร้างจาก warehouse เท่านั้น ไม่รวมออร์เดอร์ที่ยกเลิก และเก็บเฉพาะ measure ที่บวกได้ อัตราส่วนอย่างยอดเฉลี่ยต่อออร์เดอร์ ให้แดชบอร์ดคำนวณจากส่วนประกอบ จึงถูกต้องทั้งรายวัน รายสัปดาห์ และรายเดือน
